# Frozen Data Bundle

This directory contains the minimal frozen inputs used to redraw the published
Supplementary Figure 3 panels.

Included files:

- `metadata.csv`
- `parameter_grid.json`
- `matrix_gt/matrix_gt_047.txt`
- `matrix_c2c/matrix_c2c_047.txt`
- `matrix_other/matrix_other_047.txt`
- `matrix_medicc2/matrix_medicc2_047.txt`
- `manifest.json`

This bundle is for exact reproduction of the published panels. It is not needed
if you want to regenerate the study from scratch.
