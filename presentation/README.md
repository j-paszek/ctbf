## Interactive Figure User Guide

The file [`simulated_tree.html`](./simulated_tree.html) is an interactive visualization of a simulated cancer
cell evolution tree generated by the CTBF simulator. This guide is intended for users
who want to inspect the figure in more detail.

The HTML file is best viewed directly in a web browser, since it is a Plotly-based interactive figure.

The following interactions may help in exploring the figure:

1. Use `Ctrl` + `-` to adjust the browser zoom so that the whole tree is visible.
2. Hover over the root node to inspect its genotype.
3. Hover over the left edge descending from the root and then over the left child of the root.
   In this branch, no evolutionary change is shown at that step.
4. Hover over the right edge descending from the root.
   The tooltip displays the evolutionary events assigned to that edge.
5. Hover over the corresponding right child.
   The tooltip displays a copy-number profile different from the root profile.
6. By clicking `cells selected by the biopsy` in the legend, the biopsy-selected cells can be temporarily disabled or re-enabled.
7. By clicking `cells sharing the same genotype as biopsy cells` in the legend, the highlighting of all nodes sharing biopsy genotypes can be temporarily disabled or re-enabled.
8. With both of these options disabled, the figure shows the simulated full CNP-tree without biopsy-specific highlighting.
9. To reveal which cells were selected during simulated biopsies, enable `cells selected by the biopsy`.
10. The bottom-left biopsy cell `17` (`Cell ID = 17`) has `Genotype ID = 10`.
11. By following the green edges and inspecting the node tooltips, one can verify that cells `10`, `17`, and `29` share the same genotype.
12. To highlight such repeated-genotype groups across the tree, enable `cells sharing the same genotype as biopsy cells`.
13. In the simulation shown here, the root (founding-cell) genotype is preserved until the end and is selected in all biopsies; however, this is only one example, and other simulations may exhibit different patterns.

### Important note

One of the reconstruction difficulties illustrated by the figure is that the same genotype may be sampled in
multiple biopsies, but it does not need to be sampled in every biopsy in which it is biologically present.

Accordingly, the framework uses the following working assumption in the biopsy-aware setting:
if the same genotype is observed in biopsies `i` and `i+n`, it is treated as present in all intermediate
biopsy levels. The motivation is that reappearance of exactly the same genotype is considered less likely than
failure to sample a genotype that persisted but was not selected in one of the intermediate biopsies.
